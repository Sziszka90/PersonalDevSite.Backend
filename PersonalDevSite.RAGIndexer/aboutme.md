## Personal AI Website

Szilárd created a personal website using Angular and Azure Functions.

The website includes an AI assistant that answers questions about his professional experience.

Architecture:

- Angular frontend
- Azure Functions backend
- Azure OpenAI Responses API
- Azure AI Search
- Vector embeddings
- Retrieval-Augmented Generation (RAG)

The chatbot workflow:

1. User submits a question.
2. The question is converted into an embedding using Azure OpenAI.
3. Azure AI Search performs hybrid search using keyword search and vector similarity.
4. Relevant profile information is retrieved.
5. Retrieved information is sent to Azure OpenAI.
6. The AI generates an answer based only on retrieved context.
7. The response is streamed to the Angular frontend.
